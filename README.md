# Golden Jubilee - To-Do List Application

A simple, elegant to-do list application with local storage functionality. Your tasks are automatically saved to your browser's local storage.

## Features

- ✅ Add, edit, and delete tasks
- 💾 Automatic local storage persistence
- 🎨 Clean and responsive UI
- ⚡ Fast and lightweight
- 📱 Works on desktop and mobile

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Start adding your tasks!

## Files

- `index.html` - Main application file with HTML structure
- `styles.css` - Styling and responsive design
- `script.js` - JavaScript functionality and local storage logic

## How It Works

Tasks are stored in your browser's local storage, so they persist even after you close the browser window.
